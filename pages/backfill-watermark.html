워터마크 백필

기존 개체 이미지에 기본 워터마크를 적용합니다. 관리자 전용 도구입니다.

주의사항
• original_image_url이 이미 있는 개체는 건너뜁니다.
• 기존 image_url이 original_image_url로 이동되고, 워터마크 이미지가 image_url로 저장됩니다.
• 테스트 모드: 뽀 계정 소유 개체만 처리합니다. 전체 적용 전 반드시 테스트를 먼저 실행하세요.

워터마크 이미지 일괄 재생성 (종횡비 수정 반영)

이미 원본이 저장된 기존 개체의 대표·추가·성장 Step 워터마크 이미지를, 종횡비를 유지하는 새 방식(calculateWatermarkRect)으로 다시 합성합니다. 각 개체의 watermark_type에 맞춰 연구소 기본 또는 개인 워터마크를 그대로 사용합니다.
개체 하나만 재생성하고 싶으면 대상 범위에서 특정 개체를 선택하고 ID를 입력하면 됩니다.

주의사항
• original_image_url / original_additional_images / character_step_images.original_image_url은 절대 변경하지 않습니다.
• 개인 워터마크가 없거나 로드에 실패하면 기본 워터마크로 대체하지 않고 해당 개체를 건너뜁니다.
• 추가 이미지는 원본/현재 배열 길이가 다르면 해당 개체의 추가 이미지 전체를 건너뜁니다. 일부 인덱스만 성공하면 성공한 인덱스만 교체합니다.
• 새 파일은 항상 새 파일명으로 업로드되며, 기존 워터마크 파일은 자동 삭제되지 않습니다.
• 테스트 실행(dry-run)은 Storage 업로드·DB 반영을 하지 않습니다. 먼저 특정 사용자/특정 개체로 검증한 뒤 전체 적용하세요.

watermark_type 보정 (lab_black → personal)

등록/수정 경로가 watermark_type을 안 쓰던 시기의 잔재로, 실제로는 종족주의 개인 워터마크가 적용됐어야 하는데 watermark_type이 lab_black으로 남아있는 개체를 찾아 종족주의 개인 워터마크로 다시 재생성하고 watermark_type을 personal로 보정합니다.

대상 조건 (전부 만족)
1. watermark_type = 'lab_black'
2. original_image_url 존재
3. 소속 종족주의 user_profiles.watermark_url 등록됨
주의사항
• 위 세 조건을 모두 만족하는 개체가 대상입니다 — watermark_type이 실제로 틀렸다는 확정 증거는 아니라 (등록 당시엔 진짜 lab_black이었을 수도 있음) 결과를 미리보기로 먼저 확인하세요.
• original_image_url / original_additional_images는 절대 변경하지 않습니다.
• 대표 이미지가 실제로 재생성 성공했을 때만 characters.watermark_type을 personal로 갱신합니다. 추가·Step 이미지만 성공하고 대표가 실패/건너뜀이면 watermark_type은 그대로 둡니다.
• 테스트 실행(dry-run)은 Storage 업로드·DB 반영을 하지 않습니다.
• 새 파일은 항상 새 파일명으로 업로드되며, 기존 워터마크 파일은 자동 삭제되지 않습니다.

젤피렐라 대량 등록

파싱 JSON + 이미지 폴더 → 자동 매칭 → 검증 → 소량 배치 등록

1. 파일 선택

2. 검증 결과 (실제 등록 아님 — 통계만 계산)

3. 개체별 미리보기

4. 배치 등록

검증 상태가 "정상"이고, 아직 DB에 없는(char_number 미존재) 행만 실제로 등록됩니다. 나머지는 자동으로 건너뜁니다.

5. 데이터 보정 — 소유주 전체 사이트오프로 되돌리기 (1회성)

버그로 인해 소유주 닉네임이 사이트 유저 닉네임과 우연히 같으면 그 유저 계정으로 잘못 연결(owner_user_id 채워짐)된 채 등록된 개체들이 있어요. 소유주는 '새'를 포함해 전부 사이트오프여야 합니다. 아래 버튼을 누르면 이 종족의 개체 중 owner_user_id가 채워진 행을 전부 owner_user_id = null / owner_is_offsite = true 로 되돌립니다(owner_nickname 텍스트는 그대로 유지). 새로 등록되는 개체는 위 로직 수정으로 이미 처음부터 사이트오프로 등록돼요.

6. 데이터 보정 — 추가 이미지(_alt) 업로드 (1회성)

아기/성체처럼 이미지가 2장인 개체는 대표 이미지 외 나머지가 로컬에 "jellfi_XXX_alt.png"로 있어도 지금까지는 등록 시 무시됐어요(버그). 위 "2. 이미지 폴더"에서 폴더를 다시 선택한 상태(_alt 파일 포함)에서 아래 버튼을 누르면, 이미 이 종족으로 등록됐고 additional_images가 비어있는 개체 중 로컬에 _alt 파일이 있는 것만 찾아서 개별 등록 페이지와 동일한 방식(원본+워터마크 적용본)으로 추가 이미지 업로드 후 해당 행의 additional_images를 채웁니다.

7. 데이터 보정 — 분류(일반/특수개체) 재판정 (1회성)

"2세대는 전부 특수개체"로 등록했던 걸 철회하고, 1세대와 동일한 원래 규칙으로 되돌립니다: description에 "특수(개체)로 분류되었습니다" 문구가 있으면 특수개체, 없으면 일반개체. 아래 버튼을 누르면 이 종족의 등록된 개체 전체를 훑어서 이 규칙과 다르게 분류된 행만 char_categories를 정정합니다.
